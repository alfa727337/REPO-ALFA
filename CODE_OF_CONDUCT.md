# Code of Conduct

REPO ALFA is a technical project. Contributions and discussions should remain respectful, evidence-based and focused on improving the software.

## Expected behavior

- Be respectful and constructive.
- Review code and ideas rather than attacking people.
- Provide reproducible technical details when reporting problems.
- Respect the authorization and safety boundaries documented by the project.
- Do not publish private credentials, session data or personal information in issues.

## Unacceptable behavior

Harassment, threats, discriminatory conduct, deliberate disclosure of private data, spam and intentionally destructive contributions are not accepted.

Maintainers may edit, hide or remove material that violates these rules and may restrict participation when necessary to protect contributors and users.
